evo-sim

Can evolution make enough mutations fix in the available time? An open, numerical audit of Vox Day's Probability Zero / MITTENS argument and of his critics, as the groundwork for an open-source evolution simulator.

Caveat first: this is an AI-run audit with no independent human review yet. Both sides get the same scrutiny. Read the known gaps in the README before you rely on any tally.

  • Status boardCurrent counts, verdicts and open work, updated when a check is integrated.
  • Is There Enough Time? (interactive explainer)The whole story at five reading levels, with small simulations you can run in the browser.
  • Math ledgerEvery mathematical object the audit uses, with its source and the checks that rely on it.
  • Findings (HANDOFF.md)The findings so far and what is still open, on GitHub.
  • RepositoryClaims, sources, check scripts, results, reviews and milestone posts.
Research phase. No simulator code yet. Source: github.com/nickallevato/evo-sim.
