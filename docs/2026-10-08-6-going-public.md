# Milestone 6: Making it inspectable
*2026-10-08 · stage: housekeeping between R4 rounds · commits `888f586`–`3101b59`*

No research results changed in this milestone. The work made the existing results easier for someone else to check.

## All the code is in the repo
About 150 scripts and run outputs moved from the temporary session folder into the repo:
- `research/tools/` holds the harvest, claim-generation and status-board tooling.
- `research/checks/adhoc/` holds the ad hoc checks.
- `research/checks/results/raw/` holds the raw run outputs.

Scratch paths now read from `$EVO_WORK`. Full texts still stay out of git. One `git push` now updates both the private Gitea remote and the public GitHub remote.

**Note for readers:** the GitHub repository is public. It holds short quotes, metadata and hashes, but no full texts.

## The README
The README now carries:
- a scorecard, with the points where Day's maths holds up beside the points where the critics' does;
- the argument map;
- nine short derivations with proof sketches;
- a roadmap.

Its six figures are generated by `research/tools/readme_figs.py`, only from committed check outputs or from the reviewed `RESULTS.md` tables. Anyone can regenerate them and confirm they match.

## The icon
- **First version:** two diverging lineages under a magnifying lens.
- **Revision:** at the maintainer's request it was redrawn to combine a double helix and a Christian cross. The cross acts as a zipper that splits the helix into an orange strand (Day) and a blue strand (critics).
- **Files:** an animated SVG, plus static and favicon sizes and a 1280×640 social preview, all generated by `research/tools/icon.py` and `icon_raster.py`.
- **Disclosure:** this is a branding choice, and the handoff discloses it so readers can weigh it when judging the claim of neutrality.

## The handoff
[`HANDOFF.md`](HANDOFF.md) is a short briefing for a team forming its own view. It covers:
- what the project is;
- how the audit works;
- what has been found for each side;
- what is open;
- the project's own limitations;
- how to check the work.
