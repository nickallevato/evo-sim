All three follow the same seven steps, so you can move up a level without getting lost:
1. The question
2. One side's case
3. The other side's case
4. How we checked
5. What we found
6. What's still open
7. Caveats

These are drafts written before the final verdicts (stage R5), so the numbers may still change.
