# Ad hoc checks

These are small throwaway calculations made while writing the claim files and reviews: arithmetic audits, Clopper-Pearson bounds, Weasel reproductions, burn-in residuals and probes.

- `c1b_coverage_probe.py` is the one-replicate test in which lowering per-site call depth brought S21 down to about 121 (see `results/R4-C1b.md`).
- `t*.py` are one-line probes, kept only so the record is complete.

None of these is a reviewed check; the reviewed checks are in `research/checks/`.
