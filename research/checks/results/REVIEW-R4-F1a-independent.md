Confirmed: L = 200 ln 2000 = 1,520; W = 7L = 10,641 (rounding); Kimura u = 0.0198; Ub = (k/L)/(2Nu) = 1.66e-5 at k=1; predicted counts 7 / 70 / 700; observed 7.10 +- 0.36, 71.88 +- 1.16, 702.06 +- 4.73 all as printed; rate x 850 / L gives 0.56 / 5.6 / 56 (850 is about (2/s)(ln 4Ns + gamma) = 200 x 4.27, a defensible conditional time, but it is not derived in the write-up).
- **MAJOR-1.** The test is close to circular. The supply U_b is chosen so that the Kimura rate equals k/L, and the observed count is then compared with rate x W. The simulator is therefore being checked against Kimura's u, not against any alternative reading of Day. The serial reading ("count = W/L = 7 whatever the supply") is not a rival model of the simulator, it is a statement that supply equals one per latency; at k = 10, 100 it is trivially false once supply is raised. "All pre-registered predictions met" is true but each prediction was fixed by construction. The write-up's conclusion ("supply sets the count") is correct but the run does not add evidence beyond a check that `substitutions_demog` reproduces Kimura at 4Ns = 40 (already shown by B0). Recommend the write-up say so plainly; it already has "almost the F1/F1b design".
- **MINOR-1.** Dispersion var/mean = 1.53 at k=100 with 48 replicates: the standard error of a dispersion index is about sqrt(2/47) = 0.21, so 1.53 is about 2.5 SE above 1 and inside the pre-registered band only because the band was wide ([0.6, 1.6]). A real overdispersion is plausible (counts in a finite window of overlapping sweeps are positively correlated), but the self-review's "overlapping Poisson mixture" explanation is asserted, not shown.
- **MINOR-2.** The "in transit" column is rate x 850, an estimate and not a measurement (F1b measured it); labelled approximate. Fine.
- **MINOR-3.** The run is at a scaled N = 1000, s = 0.01; "his own s and N_e" in the heading means 4Ns = 40 only. The write-up says so in Method.
