# REVIEW-R4-new: h2_hard_selection_multilocus.py and c1b_day_binned_statistic.py

## 1. H2 (hard selection, multilocus)
- OK  h2:117-125,140-151. Ceiling fecundity f=min(R,K/N) gives N'/K = wbar exactly while R*wbar>1, so extinction at -ln wbar > ln R is the correct criterion. The Ricker bug was found and fixed (V1).
- MINOR h2:219,223. "lam*D < ln R" is partly an identity: D is defined as sum(-ln wbar)/n_subs, so lam*D = mean(-ln wbar). The non-trivial content is D ~ ln M + 1 (7.0 vs 6.9, 5.9 vs 6.2, 8.5 vs 8.3), which is measured independently and does check out. Reword the "predicted vs observed flip" as a test of D, not of a separate criterion. D falls as N/K falls, because p0 = 1/N (noted at lam=0.4).
- MAJOR (framing) R4-H2-hard.md "P-Day falsified". The ceiling regulation (fecundity rises whenever N<K, h2:118) is precisely the compensatory-reproduction premise of the critic's reply. It does not bias the arithmetic, but it assumes the conclusion that excess fecundity is available at no cost. Day's cap reappears at R~1.1 (ln R = 0.095, the 10%) with diploid D ~ 20-30, giving 0.095/30 = 0.003. Tested R is >=1.3 and haploid D ~ 7, so the grid never reached Haldane's regime. The supported statement is "10% is not a general bound; the bound is ln R / D". "Literal 1/300 falsified" holds only for R>=1.3 with D~7, imposed lam and free recombination (the critic-favourable choices). Downgrade to "not supported".
- MINOR h2:113-115. max_open=700 is counted as extinction (not reached at <=260 open loci).
- MINOR (pre-registration). Docstring lines 31-33 cite the V1 result, so they were edited after the first run (Ricker fix). The P-Std/P-Day block is consistent with a prior statement, but the claim "written before the first full run" should say "before the grid, after V1". The R=10 flip was predicted 0.33 and observed >0.4. n_crit ~70 at R=2 conflicts with 90 open loci persisting.
- MINOR. Flip brackets have factor-2 spacing and only 2-3 replicates. "9x-100x" is a bracket, not a measurement.
- OK/caveat h2:137-139. U=2.2 as Poisson per offspring with uniform s_d=0.02 is the maximal-load reading (Keightley's U is mostly weak or neutral). The result "U=2.2 needs R ~ e^U" is therefore an upper bound on Day's side. Fairly disclosed.
- Steelman. Day-side: finite supply (sv=0.05) and linkage are the strongest readings, and linkage is untested. Critic-side: the model concedes that lam is imposed and that there is no mutation-supply limit.
- Result stands: YES-WITH-FIXES (reword falsified; D vs criterion; pre-reg date; add R~1.1, D~20 point).

## 2. C1b (Day's binned statistic)

- MAJOR (interpretation) R4-C1b.md. "The 21 is a massive deficit vs neutral" and "sign of claim stands" are unsupported. A model that misses Day's own table (7-8k: 1,350 vs 4,497; 99.86% pre-7000 vs 38-60%) is not a valid null for his statistic. Real 1240k pseudo-haploid depth in old bins is a handful of calls, so "100%" is trivially met there and T2 ("oldest bin appearing fixed") piles events into old bins. Also, "tracked" requires data in every bin (the 27% drop). Scratch test (neutral Ne=1e4, k=1, E2-T2, 1 rep; scratchpad/t/fix.py): S21 = 6,537 / 4,180 / 1,583 / 1,204 at cov 0.3 / 0.1 / 0.03 / 0.01, and 121 at cov 0.01 with all-bin coverage required. Profile shifts toward 10000+ (63,750). Direction fixes S21 and the profile, but eligible rises to 72-138k vs 22,428, so it is not a reproduction. Ancestry structure is the second unmodelled factor (the 10000+ bin is Mesolithic, and Day's own s5.2 invokes replacement). Neither is a bug.
- Minor: starting density 1.86/q is borrowed for all Ne. Day s4.3 (79% of events start at 99-100%) is consistent with it, so eligibility is probably not the problem.
