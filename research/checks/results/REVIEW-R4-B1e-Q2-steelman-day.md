## Findings

### D1. MAJOR: under R-A's own gloss nothing in the run makes QB false; R-A external should be `supported`, not `contested` (answers correctness C4)
- **Evidence.** R-A reads "imported from the Wright-Fisher model" as "the second constraint enters from the discrete process" and "the mathematics" as "PDE (7) on the open interval" (write-up l.81; docstring l.195-197). The registered rationale for `contested` says: "false: what is needed is a Wright-Fisher import - it is model-free absorption bookkeeping, P4, and P_fix = 1/M holds in Moran and beta-binomial chains, P6b" (docstring, External R-A). Neither item reaches R-A's content:
  1. **P4 is an equivalence, not a refutation.** It shows that, given constraint 1, constraint 2 is the same statement as "mass leaving at x = 1 stays at x = 1". My check above shows both are the same as posing (7) weakly on [0, 1]. P5 (HIT) shows that (7) on the open interval fixes none of them: θ = 0, 0.5, 1 all conserve probability and give `d/dt ∫xp` of −0.101205, 0.107758, 0.31672 (raw l.42). An equivalence does not say which side is the premise. Whether one calls the extra input "mean conservation" (Day) or "absorbing bookkeeping" (the audit), it is an input that (7) does not supply. That is what R-A says.
  2. **P6b tests exclusivity, which "imported from" does not assert.** Something imported from Wright-Fisher is still imported from Wright-Fisher if Moran has it too. Chalub himself says the laws belong to "The finite population Markov processes referred above" (l.46-47), that is, Moran and Wright-Fisher (l.38-39), and that they "had to be introduced into the model" (l.43-44). Exclusivity is correctness C4's R-A0 reading, and P6b scores that reading, not R-A.
  3. **Chalub's own framing is R-A's.** "correct solution ... is a measure that not only satisfy the Kimura equation (7) but also the two conservation laws given by Eqs. (9)" (l.55-57); "two conservation laws derived directly from the discrete process" (l.147). For the continuum model, a law it does not contain and must take from another model is an input. "Assumption" is a fair name for that input.
  
  So under R-A, QB's two sentences are true: the fixation/loss split, and with it P_fix = p0 (1/(2N) for one copy), is fixed by a law carried over from the discrete process (Chalub l.147, l.43-44), and it is not produced by (7) (P5).
- **Fix.** (1) R-A external `supported`, with the basis "P5 HIT; C1, C2, C4, C13; P4 shows the imported law is equivalent to absorbing bookkeeping, which is likewise not in (7)". (2) Add R-A0 (Wright-Fisher-specific) as its own row, `misread` / `contradicted` by P6b, as C4 proposes. It cannot set the field because it is less defensible than R-A. (3) This changes the governing reading's value, so under D-24 the lead rules and a fresh reviewer checks the ruling before integration.
- **Open for the lead.** B1e's external field is now `contested`, set by the Zenodo quote's Reading A (claim file l.14: "sets the field"). The claim's title is half QB ("1/(2N) is imported from Wright-Fisher"), so the combination rule should be stated before integration. ### D3. MAJOR: "What R-A costs Day" assigns the post's context to R-B, but the post's own next sentence places the condition outside "the equation", which is R-A
- **Evidence.** The write-up (l.87) says B3c and B6 "are R-B" and that R-A governs "because rule RD takes the most defensible reading ..., not because the author meant it". In the post, B6 is followed directly by: "The diffusion has to be provided as an assumed condition that is supplied in order to solve the equation." ### D5. MINOR: Day's circularity point is verifiable in Chalub's own displays and is not credited
- **Evidence.** Day: "Chalub writes in the constraint before he solves anything, recovers it as a result two pages later". Chalub's p.3 displays "b(t) + ∫₀¹ x r(x,t)dx = ∫₀¹ x pᴵ(x)dx" (l.177), before any coefficient is computed. Since r → 0, b(∞) = ∫x pᴵ follows from that line alone, with no eigen-expansion. In the general case the conserved quantity is "∫ ϕ(x)p(x,t)dx" with "ϕ the solution of ϕ″ + ψϕ′ = 0, ϕ(0) = 0, ϕ(1) = 1" (l.147-149), which is the fixation-probability function itself. The fixation probability is literally the conserved quantity that is imposed. P3's b(∞) = 4/9 = ∫x pᴵ confirms the arithmetic.
- **Cost.** ϕ is the solution of the same diffusion's backward equation, so for ψ ≠ 0 the imposed quantity is itself a diffusion result (relevant to R-B, not to R-A). The result appears on p.4 ("Finally, the time-dependent fixation probability is given by", l.210), one page after (9), not two. That is an immaterial slip under R1.
- **Fix.** Add a Day bullet with these two quotes and locators. Record "two pages" → one page in the slip ledger.
