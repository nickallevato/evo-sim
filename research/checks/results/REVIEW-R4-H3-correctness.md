## 2. What I checked and found correct (OK)

**Model code (`run()`), read line by line.**
- *Per-generation order:* locus opening (Poisson λ, random chromosome and position) → ceiling reproduction f = min(R, K/N) with J = ⌊fN⌋ + Bernoulli(frac) juveniles → parent choice (uniform, or soft-weighted with distinct-parent redraw) → crossover origins → new deleterious mutations (Poisson(U/2) per gamete, added to the recombined bin counts) → viability = Bernoulli(w), w = e^{−s·anc}[×e^{−s_d k} if hard] → survivors become the adults → finite-supply mutation → fixation/loss/reseed. Recombination → mutation → selection is the standard order, and nothing is selected before it arises.
- *Recombination:* the cumulative XOR of independent Bernoulli(r) per interval, with r = ½(1 − e^{−2d}) (Haldane, d in Morgans) and 0.5 across chromosomes, is correct. The `uint8` cumsum wraps mod 256, but only parity is used. First-point origin is Bernoulli(0.5). Bins first, loci last in `P`; `hap[:, :B]` and `hap[:, -nl:]` are consistent with that. Map 23 × 1.6 = 36.8 M; the "free" and "short" maps are as described.
- *Genotype → fitness:* `anc = 2·nl − Σ derived over the two gametes` and `2·len(waiting)` for waiting loci is right; log-additive; the reshape (J, 2, nl) matches `par[0::2], par[1::2]`; `gidx` for survivors matches `Cg[gidx].T` and `Dc[gidx]`.
- *Hard vs soft load:* hard multiplies survival; soft only weights parents by the previous generation's `wd` (re-indexed to survivors, `soft_w = wd[surv]`). Soft therefore has no demographic effect by construction, and the stage-B finding "persistence the same as with no load" is a consequence of that construction, not an independent result (the informative B output is p_fix and D under background selection). Load measured Ld = 2.25 ≈ U ✓.
- *R and the criterion:* equilibrium N = K·w̄ while R·w̄ > 1, extinction when −ln w̄ > ln R; extinction at N < 20, J < 2, or > 3,000 open loci (never reached on the grid). Persistence = no extinction through burn-in + window (extinction during burn-in counts as non-persistence).
- *D estimator:* D = Σ_window(−ln mean_j e^{−s·anc_j}) / fixations in the window. Reseeded lost copies stay in the sum, so D includes the failed attempts, as claimed. There are mild edge effects (sweeps straddling the window) and run-level ratios averaged without weights in `summarize` (sparse R ≤ 1.1 cells have 8-30 fixations). Neither changes the 15-17 conclusion.
- *Seeds:* `SeedSequence([SEED, code, ci, rep])`; `ci` is assigned before the cost-sort, so seeds are order-invariant; `wfD` uses code 9; P uses `[20261051, cell, rep]`. Run counts per stage match the cell definitions (A 672, V 60, B 96, C 48, S 24, P 84).
- *λ50 and Wilson:* both implementations are standard; `lam50` takes the first downward crossing and returns NaN with a bracket if none.
- *φ definition:* λ50/λ* with λ* = ln R/(2 ln 2K); using D_obs instead (15-17 at K = 1000) would raise φ by up to 10%; the write-up's choice is conservative and documented.
