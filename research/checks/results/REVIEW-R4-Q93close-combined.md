## 3. Steelman: critic side

- **K1 (MINOR). The window-free reading deserves a headline place.** "Neutral substitution" is rate vocabulary (the comment is explicitly about Kimura's k and a per-fixation time), and a rate is a steady-state quantity. The withdrawal rationale "Q93 names no window" cuts both ways: with no window named, the unbounded reading is the default and any window is an import (D2). W1 gives k = mu at every N: false at every N, no cutoff. The write-up records W1 (OFF, rhetoric) but ranks it by status, last. Fix: in the proposed Q93 comment, lead the readings with "no window stated: false at every N (rate = mu); true only if a window of about 1 My or less is imported".
- **K2 (NOTE). Ruling on whether `dialectic` on a SLACK reading is too generous: consistent with precedent, so it stands, with a qualifier.** Q96's R3 (fixation count, "true as a count", cutoff unconstrained) is tagged `dialectic` as the verdict-field value; RH-18 and RH-15 H1 are `dialectic` because literally true. A universal "any population over X" is true at X whenever the real cutoff is below X, so TRUE is correct. What the tag must not carry is the step to a "hard limit" at 10,000, already scored at claim C (X1 row C). The proposal says this; keep it in the tag comment.
- **K3 (NOTE). Cd rows score a different object.** F_drift is drift variance, not a fixation count. It is plausible here because the preceding sentence speaks of a limit to drift "affecting a population", but under RD an extended object cannot set the verdict field. The rows are not selected, so no harm. They add 2 of the 13 OFF rows, which is another reason for C4.
- **K4 (MINOR). Symmetry of application.** The 3x band is applied to the cutoff N*, while Q96 and Q157/Q158 applied it to the value at the stated N_e (F_drift versus 3e-4; F versus 0.30). The write-up discloses this (Caveats) and gives value / band in the table. One real difference: for Q96, the fixation-count reading was explicitly not a reading of the statement's object and sat in the verdict field only via RD; for Q93 "substitution will not fixate" is the fixation object itself, so the count reading is more direct here. Fix: one sentence in the write-up saying the value-vs-cutoff difference exists and that the value-based test (W4 wright Cc: 3.5 mean fixation times) agrees on direction.

## 4. Rulings on the three write-up doubts

- **3(a) "Remotely close": threshold or truth?** For a universal of the form "any population over X, P", it is true iff the true cutoff is at or below X, so truth at the named threshold is the literal criterion; the earlier tests (Q96 R3, RH-18, RH-15) accepted a true statement as `dialectic` without a slack test. Slack does not make the statement false. But the registered two-sided "LOCATED" column is the right sensitivity: a `dialectic` that rests only on slack should be marked as such, and here it does not need to, because the located reading (W4 / Ne / Cc, 20,000) also passes (D1). Ruling: the tag stays `dialectic` under either test; record the slack and the located readings side by side.
- **3(b) Is importing the 7,000-year window licensed under S/C?** Yes as a reading (author's own stated figure, same thread, evidence named in the next sentence; rule C ranges over ambiguous referents), no as the unique reading (D2). The tag must name the import.
- **3(c) Which selection does RD require?** RD defines the verdict-field reading as the one under which the statement is "most defensible (closest to literally true, best supported)", not the best verdict for the speaker, and not "closest textually". Status-first is therefore the faithful reading of RD, and textual anchor is only a tie-break. Hard Limits' census frame would not be selected on either ordering: the textually close HL reading in the comment's own N_e frame is W4 / Ne / Cc, which is CLOSE and `dialectic`, not `rhetoric` (C2). So the write-up's Open 3 ("the value would be `rhetoric`") holds only for the census sub-reading; fix that sentence.
