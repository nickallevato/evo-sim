## 4. SYMMETRY (key question)
- **Band, readings, standard.** Same 3x/one-third band, same "any in-scope passes" headline, same extended-readings policy, same per-reading reporting as R4-RHclose. Same direction of strictness: a narrow band yields more rhetoric for both sides. In that sense the treatment is symmetric in rule. Two places where it is not symmetric in application: (i) MAJOR-1: the Drosophila match is generous to Day's computation and strict toward the critic's claim, the opposite of rule C towards the speaker; (ii) MINOR-2: the "predict" reading was left out for the critic but, in R4-RHclose, alternative readings were added after review for Day (RHclose MAJOR-1/2), so critics got fewer registered readings on first pass.
- **Structural asymmetry stated?** Yes. "Verdict effects" says critic rhetoric statements are "Not scored" by default, so the rule "adds no new negative", while for Day rhetoric removes adverse verdicts; and the Review note in R4-RHclose (line 134 there) already flags it. That is stated honestly. What is not stated: the asymmetry has a second face. A critic statement tagged dialectic is exposed to scoring only if it is **false**; here none was tagged dialectic and false, but M2 shows a dialectic-core claim contradicted (the "sequential" method description) that is recorded only under G2e fidelity `partial`, not as an error.
- **Owed?** (a) Recommended, not required: add M2 (Myers's sequential description of MITTENS 3.0 vs s8.1; PZ-04 sibling paragraph, quoted) to `ledgers/slips.md`/the critic-arithmetic ledger as a slip with the R1 check (does correcting it move his conclusion >25%? it removes his main argument against MITTENS 3.0, so probably an error, not a slip) so Day-side scrutiny of critics is as prominent as the Day slips; the write-up is silent on this. (c) The write-up should say explicitly that critic rhetoric tags cannot produce a verdict change, so the *test* has no downside for critics while the Day test did; it does so partly (see above).
