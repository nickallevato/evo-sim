## Findings

**MAJOR-1 (registration record: the table was known before the "pre-registration").** `a2e_alpha_uricchio.py` l.3-5 says: "What was NOT known when this is written: the full-text method, the table (including HPDs for the weak/strong split) and the study's own fixation counts." Two facts contradict this:
(a) Commit a44767f (2026-10-11 19:57:50), 33 minutes before 7d68de9, filed `refresh-2026-10-11b-lit.md` l.30 with the whole Table 1. That includes total 0.135 (0.096, 0.17), strong 0.041 (0.0, 0.13), non-VIPs 0.12 (0.09, 0.15), aMK 0.076 and the 29,925 / 38,135 counts.
(b) The docstring's own registered quote list (l.62) contains the Table 1 row verbatim, HPDs included.
So P2-P4 and blockers (3)-(4) restate values already in hand. P2 says "≥ 5" when 5.49 was known. P3 says "0" and "≥ 450" when 455 was known. Blocker (4) is 798 > 191. None of them could have failed. The only element written before the full text is milestone 13's trigger (e68816e, 14:10:41). It was written with the abstract's 0.135 known, and it names a source ("a full-text Uricchio"), not a result. `PREREG-STATUS.md` l.98 rates this check `criterion-only` on the strength of docstring l.3. **Effect on the value:** none, because the numbers are what the paper prints. **Effect on the record:** the field moved on a check that could not fail after the data were seen. That bears on certainty (GRADE A2e row, ST#55), not on the arithmetic. **Fix:** relabel P2-P5 and blockers (3)-(4) "values known before registration (a44767f); reproduction". Correct docstring l.3-5 in a post hoc commit. Change PREREG-STATUS l.98 to say that only the milestone-13 trigger predates the table. In the claim comment and the R4-A2e-alpha addendum, call the move "a reproduction of a published interval against Day's own 191", not a pre-registered test.

**MAJOR-2 (the field's literal scope includes an estimate below the flip; the exclusion that carries the value is not stated in the field).** Claim l.14 scopes the value to "model-inferred alpha". The record holds one human-branch, model-inferred alpha below the flip: Gayà-Vidal's 0.2%, which maps to 29-49 (`R4-A2e-alpha.md` l.21). It also holds one abstract-only reading that straddles the flip (Eyre-Walker & Keightley "little evidence", 0-1,223, l.28). The record sets both aside for documented and, in my reading, sound reasons:
- GV is a frequency-filtered MK value without a correction for slightly deleterious polymorphism, and its authors flag it as a possible underestimate (l.44, l.47).
- EK is human-macaque, abstract only, and the 0-5% figure is the audit's reading (l.28, l.112).
- Uricchio's own text says "Deleterious polymorphism effectively makes the test overly conservative". The paper's aMK on the same data, which does correct for deleterious polymorphism, already gives 0.076, i.e. 843 = 4.4x.

But the value holds only after this step, and the field does not say so. Read literally, the field's scope contains an in-scope estimate on Day's side of the flip, and a reader of l.14 cannot see why that estimate does not count. Milestone 13's trigger did say "bias-corrected human-branch alpha" (`docs/2026-10-11-1-…md` l.27). The field dropped "bias-corrected". **Fix:** this is wording only and leaves the scope unchanged. Add to the Basis sentence of l.14: "on bias-corrected estimates; Gayà-Vidal's 0.2% (29-49) is set aside as an uncorrected MK value its authors flag as a possible underestimate, and Uricchio's aMK on the same data, corrected for deleterious polymorphism only, gives 843 (4.4x)". If the fix-pass author holds that adding "bias-corrected" narrows the D-12 scope, the step goes to the lead (D-24). The question to put is: does "model-inferred alpha" include uncorrected MK? If it does, the in-scope evidence straddles the flip.

**MINOR-3 (gene-set transfer not tested; it survives).** The audit applies Uricchio's alpha for the whole gene set to the counts N1-N3, which come from other gene sets. Uricchio warns that their estimate and earlier ones "are not directly comparable" because "we use a much larger set of genes". The obvious in-paper sensitivity is the non-VIP row (23,676 NS; alpha 0.12, HPD 0.09-0.15, verbatim from Table 1). At the non-VIP lower HPD the count is 0.09 x 11,090 = 998 (5.2x), or 749 (3.9x) with the haircut. **Fix:** add this row to the addendum as a gene-set sensitivity. It does not move the value.

**MINOR-4 (evidence set not gathered by a stated search).** The basis comprises Boyko 2008, Uricchio 2019, EK 2009 (abstract) and GV 2014. They were gathered without a search strategy (AR-05 open; the GRADE A2e row codes selection as "suspected"). RG-03 still lists a human-branch-polarised bias-corrected count and a non-coding count as open. This review cannot say whether the set is complete; it can only say what the set carries. **Fix:** in l.14, write "on the estimates gathered (Boyko 2008, Uricchio 2019; GV 2014 and EK 2009 set aside, MAJOR-2)", so that the value is tied to a named set. Cross-reference L3 (roadmap A12), the audit's own estimate.

**NOTE-1 (the lead's two suspected steps work in Day's favour).** The brief names the 25% haircut and the choice of lower HPD over the point estimate as the steps to attack hardest. Both lower the count. Without them, the point estimate on N2 gives 1,497 (7.9x), and the lower HPD with no haircut gives 1,065 (5.6x). Neither step can be what makes the field over-reach. The haircut is not a correction: Uricchio's sentence ("in this adaptation regime α is reduced ≈ 25% by linkage genome-wide") describes the true alpha under their BGS model, and 0.135 is already inferred under that model. Applying 0.75 again is therefore an arbitrary charity factor. That is honestly labelled "charity" in l.14, but it is not something rule C licenses, because rule C is about reading quotes. Survival condition inside the scope: A2e holds only if Uricchio's lower-HPD alpha overstates the true value by at least 5.6x on N2, i.e. at least 82% of the inferred adaptive substitutions are artefact. With the haircut the figures are 4.2x and 76%. Uricchio report seven confounders tested ("are unlikely to substantially influence the results", see Supplementary Information, which I did not read).

**NOTE-2 (the flip).** 191 is Day's own figure (Q139, MITTENS 3.0 s7.3 p.13: "At 1,322 gen/fix (non-mutator): 191 achievable."). Against the other flips on record (158.8 at 1,587; 179.0 at Day's adaptive-only 1,408), 191 is Day-favourable. Yoo's generation count gives 194.5, and 798/194.5 = 4.10x. The choice does not matter. The coding-only count is a subset of all adaptive fixations, so the comparison is conservative for the critic side (`R4-A2e-alpha.md` l.45).

**NOTE-3 ("independent").** `R4-A2e-alpha.md` l.165 calls Uricchio "a second, independent … estimator". On data that is true: 1000 Genomes against Boyko's sample. On method it is not: both are in the MK/SFS family, which the m8 fix already wrote at l.60, and Uricchio states that its estimate "is similar to previous estimates [40, 23]" (Boyko 2008; Messer & Petrov 2013). The aMK 0.076 is the same data, not a third source. **Fix:** l.165 should use the l.60 wording.

**NOTE-4 (alpha\* range).** On N1-N3 the alpha\* maximum is 1.72% (G1, N2), which the record rounds to 1.75%. On the paper's own base, alpha\* is 0.64% (G1) and 0.53% (G2), below the stated "0.65-1.75%". This is harmless, and the 5.5x headline is unchanged (0.096/0.0172 = 5.59).

**NOTE-5 (re-runnability).** The script's hard-coded source path no longer exists on either host, so the script cannot be re-run as committed. The re-fetch has the same hash. The fix pass may point the path at any directory holding that hash.

**NOTE-6 (vocabulary).** `contradicted` has no written evidential threshold (METHOD-AUDIT l.192 on `contested`; the GRADE A2e row is very low under every mapping). This is outside a correctness review. It is listed because it decides what "carries" means.
